Browser audio rule
Call startScore() from a click, tap, or keypress. Browsers block audio before user interaction.

      
Transition rule
State changes wait until the next bar, so combat never enters with an ugly mid-chord cut. The log above shows exactly when each change lands.

      
Performance rule
Reuse one score instance. Call disposeScore() only when leaving the game entirely.
