From editor to game

Let the world conduct.

Canopy waits for safe musical boundaries, then changes tempo, density, bass, and percussion in response to your game state. The exported Tone.js runtime is the realtime instrument and conductor; the MIDI sketch is just a compact list of notes for polishing ideas in a DAW — use both, for different jobs.

Browser audio rule
Call startScore() from a click, tap, or keypress. Browsers block audio before user interaction.

      
Transition rule
State changes wait until the next bar, so combat never enters with an ugly mid-chord cut.

      
Performance rule
Reuse one score instance. Call disposeScore() only when leaving the game entirely.
